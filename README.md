# Chrome-proxy

#### 介绍
用于多网络公司分别设置代理,可以自由的设置浏览器的代理,独立于系统代理设置,每次启动浏览器时生效,自动保存设置,无需手动开启,可能会出现代理服务器未设置正确导致无法上网的情况出现

#### 软件说明书
支持Edge、Chrome等基于Chromium的浏览器


#### 安装教程

1.  直接下载源代码
2.  解压
3.  在浏览器中启用开发者模式,加载解压缩的扩展,选中解压目录
